# ux-design

Designing how digital products work and feel for the people who use them: user research and discovery, information architecture, interaction design, user flows, wireframing and prototyping, visual and UI design, design systems and design tokens, accessibility, UX writing, and usability evaluation, for web, mobile, desktop, and data-dense applications. Software architecture and back-end implementation belong in `software-engineering`; analysing product data belongs in `data-science`; brand identity, logos, illustration, and print would belong in a future `graphic-design` domain.

Core persona: `the-uix-designer`. Specialized skills (for example a focused accessibility audit, design-system migration, or dashboard design) are named descriptively, without `the-`.
