# ml-engineering

Building and operating predictive machine learning systems end to end: framing business decisions as ML tasks, data collection and labeling, data validation, EDA for modeling, feature engineering, training and tuning (tabular models, time series forecasting, recommendation, anomaly detection, and deep learning on text or images inside a larger system), rigorous evaluation, and MLOps (packaging, serving, registries, CI/CD, monitoring, retraining). Camera and video systems belong in `computer-vision`; applications built on large language models in `ai-engineering`; statistical analysis, experimentation, and exploratory insight without a production model belong in `data-science`; general software architecture in `software-engineering`.

Core persona: `the-ml-engineer`. Specialized skills (for example a forecasting pipeline, a recommender builder, or a model-monitoring setup) are named descriptively, without `the-`.
