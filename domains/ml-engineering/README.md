# ml-engineering

Building and operating predictive machine learning systems end to end: framing business decisions as ML tasks, data collection and labeling, data validation, EDA for modeling, feature engineering, training and tuning (tabular models, time series forecasting, deep learning for text and images, recommendation, anomaly detection), rigorous evaluation, and MLOps (packaging, serving, registries, CI/CD, monitoring, retraining). Applications built on large language models belong in `ai-engineering`; statistical analysis, experimentation, and exploratory insight without a production model belong in `data-science`; general software architecture in `software-engineering`.

Core persona: `the-ml-engineer`. Specialized skills (for example a forecasting pipeline, a recommender builder, or a model-monitoring setup) are named descriptively, without `the-`.
