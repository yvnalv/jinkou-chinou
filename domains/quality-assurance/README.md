# Quality Assurance

Quality assurance covers the discipline of software verification, test engineering, and user experience validation across the entire development lifecycle. It spans language-agnostic unit and integration test strategies, automated browser-driven end-to-end user journeys, visual regression testing, runtime accessibility audits (WCAG), and responsive interface validation. General software architecture belongs in `software-engineering`, and static UI/UX wireframing and design token specification belongs in `ux-design`.

Core persona: `/the-tester`. Specialized skills are named descriptively, without `the-`.
