# The Motion Designer — Programmatic Video & Motion Graphics

Design, choreograph, and render frame-accurate motion graphics, promotional videos, SaaS product demos, kinetic typography reels, and animated brand assets programmatically using **Remotion** (`remotion-dev/remotion`, React + TypeScript).

Every animation generated by this skill is **100% fact-grounded in official Remotion v4.x APIs**, strictly isolated by **Brand Profile** (so different brands like GLM, Databro, or custom client folders never mix), and engineered around **Social Media Platform UI Safe Zones** so native platform overlays (Like/Comment/Share buttons, usernames, captions, and progress bars) never block subtitles, logos, or focal visuals.

```text
Run 4-Step Option Wizard → Lock Brand & Safe Zone → Storyboard Frames → Code Deterministic Scenes → Validate → Preview / Render
```

## When to Use

* Creating programmatic motion graphics, product launch videos, explainer animations, or social media reels using Remotion (React/TypeScript).
* Designing multi-platform video compositions formatted for Instagram (Reels, Stories, 4:5 Feed), TikTok, YouTube (Shorts, 16:9 HD/4K), LinkedIn, Facebook, or X with guaranteed UI overlay safe zones.
* Applying or onboarding isolated brand guidelines (colors, fonts, logos, spring physics, lower-thirds) for specific brands (e.g., GLM, Databro) without cross-brand contamination.
* Exporting animations to MP4 (`H.264`/`H.265`), WebM (including transparent alpha `yuva420p`), Apple ProRes `4444` (`.mov` with alpha), looping GIFs, PNG frame sequences, or still graphics (`PNG`, `WebP`, `JPEG`, `PDF`).
* Embedding interactive, resolution-independent 60fps animations directly inside web applications using `@remotion/player`.
* Auditing or repairing broken/flickering Remotion projects caused by hallucinated CSS transitions, unclamped interpolations, or unawaited media tags.

Do not use it for: static UI/UX app wireframing without motion (use `the-uix-designer`), automated E2E browser testing (use `ui-ux-testing`), or computer vision video analytics (use `the-cv-engineer`).

## Mandatory Pre-Generation Option Wizard (Always Ask First)

> [!IMPORTANT]
> **Never guess or assume the brand, platform, video style, or export format.**
> Before generating storyboards or Remotion code (unless the user already specified all 4 choices in their prompt), present the **4-Step Pre-Generation Option Wizard** below and wait for the user's confirmation. Whenever any detail (copywriting, logo path, color hex, audio sync, or duration) is unclear, **ask the user rather than inventing placeholders**.

### Step 1 — Brand Guidelines & Style Isolation
Ask which brand profile to apply (each brand is strictly isolated and never mixes assets or colors with other brands):
1. **Select an Installed Brand Profile / Skill**: e.g., **GLM**, **Databro**, or any installed `*-brand-motion` skill in the workspace.
2. **Load from a Brand Guidelines Folder / File**: User provides a path to their brand folder (logos, custom fonts, hex palette, PDF/Markdown guidelines, or `brand.json`).
3. **Neutral / Custom Style**: User specifies primary/accent colors, dark vs. light background, and typography style for a standalone project.

### Step 2 — Deliverable Type & Export Format
Ask what final output format is needed (`references/export-formats-and-codecs.md`):
1. **Standard Video (`MP4 H.264` / `H.265` / `WebM`)** — Multi-scene video with transitions, audio, and optional captions.
2. **Transparent Motion Overlay (`Apple ProRes 4444 .mov` / `WebM Alpha` / `PNG Sequence`)** — Lower-thirds, logo stingers, or UI callouts with alpha channel transparency.
3. **Seamless Animated Loop (`GIF` / `WebM`)** — Looping product feature animation for documentation, GitHub READMEs, or chat.
4. **Dynamic Still Graphic / Slide (`PNG` / `WebP` / `JPEG` / `PDF`)** — Social thumbnail, OpenGraph banner, or printable slide via `npx remotion still`.
5. **Interactive Web Player (`@remotion/player`)** — Live 60fps React animation component embedded directly in a web application.

### Step 3 — Motion & Visual Style
Ask which visual direction fits the message (`references/motion-styles-and-choreography.md`):
1. **SaaS UI & Product Walkthrough** — App screen mockups, simulated cursor clicks, smooth pan/zoom camera focus, and feature callout badges.
2. **Kinetic Typography & Social Reel** — High-energy text reveals, spring physics, and TikTok/Reels-style word-by-word highlighted captions.
3. **Enterprise / Corporate Explainer** — Clean structured scenes, workflow/architecture diagrams, and professional brand lower-thirds.
4. **Data Storytelling & Infographics** — Animated bar/line charts, KPI number counters, and comparison timelines.
5. **3D & Shader Motion** — 3D device/logo scenes (`@remotion/three`) or GPU shader backgrounds (`@remotion/skia`).

### Step 4 — Target Platform First, Then Placement & Aspect Ratio
Ask **which platform** the content will be published on first, then confirm its placement preset and UI safe zone (`references/social-media-safe-zones.md`):
1. **Instagram**:
   - **A. Reels (`9:16`, `1080×1920`, 30/60fps)** — Protects top `285px`, bottom `672px`, right `120px` action icons, **and** keeps key hooks + subtitles inside `Y: 285–1248px` so the `4:5` Home Feed crop never cuts them off.
   - **B. Stories (`9:16`, `1080×1920`, 30/60fps)** — Protects top `250px` story bars and bottom `340px` reply bar.
   - **C. Feed Portrait (`4:5`, `1080×1350`, 30/60fps)** — Maximum feed screen real estate; protects bottom `160px` controls.
   - **D. Feed Square (`1:1`, `1080×1080`, 30fps)** — Classic square feed layout.
2. **TikTok**:
   - **In-Feed / Organic / Spark Ad (`9:16`, `1080×1920`, 30/60fps)** — Protects top `240px`, bottom `660px` (4-line expandable caption + sound marquee), and right `180px` engagement button stack.
3. **YouTube**:
   - **A. YouTube Shorts (`9:16`, `1080×1920`, 30/60fps, up to 3m)** — Protects top `288px`, bottom `672px` (Channel + Subscribe + Title), and right `192px` action column.
   - **B. YouTube Standard HD / 4K (`16:9`, `1920×1080` or `3840×2160`, 30/60fps)** — Protects bottom `160px` player scrubber and top `90px` info bar.
4. **LinkedIn**:
   - **A. Feed Portrait (`4:5`, `1080×1350`)** | **B. Square (`1:1`, `1080×1080`)** | **C. Mobile Vertical (`9:16`, `1080×1920`)** | **D. B2B Landscape (`16:9`, `1920×1080`)**.
5. **Facebook**:
   - **A. Facebook Reels / Stories (`9:16`, `1080×1920`)** | **B. Feed Portrait (`4:5`, `1080×1350`)** | **C. Feed Square (`1:1`, `1080×1080`)**.
6. **X (Twitter)**:
   - **A. Landscape Demo (`16:9`, `1920×1080`)** | **B. Square (`1:1`, `1080×1080`)** | **C. Vertical (`9:16`, `1080×1920`)**.
7. **Universal Multi-Platform Short-Form Master (`9:16`, `1080×1920`)**:
   - Uses the strictest union safe box (`X: 60..888px`, `Y: 288..1248px`, with Subtitles/CC anchored at `Y: 1040..1200px`) so a **single exported MP4** posts cleanly to Instagram Reels, TikTok, YouTube Shorts, and Facebook Reels without any UI overlap.
8. **Website / Pitch Deck / Custom Resolution**:
   - Custom dimensions, transparent overlays, or widescreen presentations without social UI dead zones.

## Operating Modes

| Request | Mode | Primary Output |
|---|---|---|
| Plan a new video/motion piece, choose brand & platform, map scenes | **A — Wizard, Brand Lock & Storyboard** | `STORYBOARD_SPEC.md` (awaiting user approval) |
| Scaffold or code Remotion compositions, scenes, captions, and transitions | **B — Deterministic Scene Implementation** | Verified Remotion `.tsx` components + `validate_remotion_project.py` report |
| Render video, transparent overlay, GIF loop, or still graphic | **C — Multi-Format Render & Export** | Exact `npx remotion render` / `still` execution & exported artifact |
| Create an isolated brand token pack or dedicated `<brand>-brand-motion` skill | **D — Brand Profile Onboarding** | Isolated `brand.ts` token module or new specialized brand skill |
| Fix flickering animations, CSS transition bugs, or version mismatches | **E — Anti-Hallucination Audit & Repair** | Diagnostic JSON report + repaired frame-deterministic code |

### Mode A — Wizard, Brand Lock & Storyboard
1. **Run the 4-Step Option Wizard**: Confirm Brand Profile, Deliverable Format, Motion Style, and Platform/Aspect Ratio + Duration.
2. **Inspect Brand Assets**: Read the selected brand's tokens (`references/brand-system-architecture.md`) or inspect the user's brand folder for logos, fonts, and hex codes. Never mix tokens from another brand.
3. **Compute Frame Budget & Safe Zones**: Convert duration in seconds $\times$ `fps` into exact frame ranges for each scene and transition (`references/remotion-core-api.md`), and lock the platform's safe-zone bounding box (`references/social-media-safe-zones.md`).
4. **Draft Storyboard**: Produce a scene-by-scene storyboard from `references/STORYBOARD_SPEC.template.md` and get user approval before coding.

### Mode B — Deterministic Scene Implementation
1. **Scaffold / Inspect Remotion Project**: Ensure `@remotion/*` packages share the exact same version. Use `assets/brand-tokens.starter.ts`, `assets/Root.starter.tsx`, `assets/SceneTemplate.starter.tsx`, and `assets/SafeZoneOverlay.starter.tsx`.
2. **Implement Frame-Driven Scenes**:
   - Drive every animation exclusively from `useCurrentFrame()` with `spring()` or clamped `interpolate()` (`references/remotion-core-api.md`).
   - Place all primary content inside the platform's safe content box and anchor all subtitles/Closed Captions (CC) inside the platform's **CC Safe Band** (`references/social-media-safe-zones.md`).
   - Embed `<SafeZoneOverlay />` (enabled via prop in Studio preview, automatically hidden during rendering) so the user can visually verify safe zones.
3. **Run Deterministic Validator**: Execute `python <skill-dir>/scripts/validate_remotion_project.py --path <target>` and fix any flagged violations before finishing.

### Mode C — Multi-Format Render & Export
1. **Verify Project Readiness**: Run `scripts/validate_remotion_project.py` to confirm zero banned CSS animations or package version mismatches.
2. **Select Codec & Flags**: Match the user's chosen format from `references/export-formats-and-codecs.md` (e.g., `--codec=h264`, `--codec=prores --prores-profile=4444` for alpha overlays, `--codec=gif`, or `npx remotion still --image-format=png|webp|pdf`).
3. **Execute or Provide Render Command**: Run the render command (or launch `npx remotion studio` if the user wants to preview interactively first) and report the output file path, resolution, duration, and codec.

### Mode D — Brand Profile Onboarding
1. **Ingest Brand Materials**: Ask the user for the brand name (e.g., `GLM`, `Databro`) and their brand guidelines folder/files (colors, fonts, logos, voice/style).
2. **Generate Isolated Brand Token Module**: Create a self-contained `<brand>.brand.ts` from `assets/brand-tokens.starter.ts` (or coordinate with `the-skillsmith` to scaffold a dedicated `domains/creative-media/<brand>-brand-motion/` specialized skill per `references/brand-system-architecture.md`).
3. **Verify Isolation**: Ensure the new brand profile has zero imports or references to any other brand's assets or tokens.

### Mode E — Anti-Hallucination Audit & Repair
1. **Run Validator**: Execute `python <skill-dir>/scripts/validate_remotion_project.py --path <project-dir> --json`.
2. **Repair Violations**:
   - Replace CSS `transition`, `@keyframes`, and Tailwind `animate-*` classes with `useCurrentFrame()` + `spring()` / `interpolate()`.
   - Replace `<img>` with `<Img>`, `<video>` with `<OffthreadVideo>`, and raw relative asset strings with `staticFile()`.
   - Add `{ extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }` to unclamped `interpolate()` calls.
   - Align mismatched `@remotion/*` package versions in `package.json`.
3. **Re-Validate**: Re-run `validate_remotion_project.py` until 0 errors remain.

## Rules

### 1. Strict Fact-Based Remotion Grounding (Zero API Hallucination)
* **Never use CSS `transition`, CSS `@keyframes`, Tailwind `animate-*` (such as `animate-spin`, `animate-pulse`, `animate-bounce`), `requestAnimationFrame`, `setTimeout`, or `setInterval` to animate elements.**
  * *Why:* Remotion renders frames in parallel and out of order across multiple headless browser tabs. Time-based CSS or JS timers are not synchronized to `useCurrentFrame()`, causing severe flickering, jumps, and broken renders.
* **Always drive 100% of animations from `useCurrentFrame()`** using `spring()`, `interpolate()`, `@remotion/transitions`, `@remotion/paths`, or `@remotion/three`.
* **Always use Remotion's asset-aware components**: `<Img>` instead of `<img>`, `<OffthreadVideo>` (or `<Video>`) instead of `<video>`, `<Audio>` instead of `<audio>`, and `staticFile('filename')` for files in `public/`.
* **Always clamp `interpolate()`**: Include `{ extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }` by default so values do not overshoot before or after the keyframe range.
* **Never invent `@remotion/*` APIs or hooks**: Only use documented exports verified in `references/remotion-core-api.md` and `references/packages-and-capabilities.md`.

### 2. Strict Brand Isolation Guarantee
* Every brand (e.g., `GLM`, `Databro`, or client brands) must live in its own isolated token file or dedicated specialized skill folder (`references/brand-system-architecture.md`).
* **Never mix colors, fonts, logos, or lower-third components from one brand into another.**
* Always ask which brand to use during the Pre-Generation Wizard before generating scenes.

### 3. Social Media UI Safe-Zone & Subtitle (CC) Protection
* When generating for any social media platform (`Instagram`, `TikTok`, `YouTube`, `LinkedIn`, `Facebook`, `X`), **never place titles, key visuals, logos, or Closed Captions (CC) inside the platform's UI dead zones** (`references/social-media-safe-zones.md`).
* On `9:16` (`1080×1920`) vertical videos:
  - Keep the **top `240–288px`**, **bottom `650–672px`**, and **right `120–192px`** clear of critical text and subtitles.
  - Anchor Closed Captions / subtitles in the **CC Safe Band (`Y: 1040px to 1220px`, `X: 60px to 888px`)** so they sit above the bottom caption/username block, to the left of the Like/Comment/Share buttons, **and** inside Instagram's `4:5` (`Y: 285px to 1248px`) Home Feed preview crop.

### 4. TransitionSeries Frame Math Rule
* When using `<TransitionSeries>` from `@remotion/transitions`, remember that transitions **overlap** adjacent scenes:
  $$\text{Total Duration} = \sum \text{Scene Durations} - \sum \text{Transition Durations}$$
* Always account for transition overlap when setting `durationInFrames` on `<Composition>` so the video does not end early or render trailing black frames.

### 5. Ask-When-In-Doubt Rule
* Whenever the user's request leaves the brand, target platform, aspect ratio, export format, duration, or script copy ambiguous, **pause and ask the user with structured options** before writing code.

## Definition of Done

* The 4-Step Pre-Generation Option Wizard (Brand, Format, Style, Platform/Aspect Ratio) has been confirmed with the user.
* All brand colors, typography, and logos come strictly from the selected brand profile with zero cross-brand leakage.
* All titles, focal graphics, and Closed Captions (CC) respect the target platform's UI overlay safe zones (and include `<SafeZoneOverlay />` for Studio preview).
* `python <skill-dir>/scripts/validate_remotion_project.py` passes with zero errors (no CSS transitions/keyframes, no raw `<img>`/`<video>`, no `@remotion/*` version mismatches).
* Exact preview (`npx remotion studio`) and export (`npx remotion render` / `npx remotion still`) commands are provided or executed.
