# GLM Systems Brand Kit

Standardized brand kit directory for **GLM Systems (`glmsystems.com`)**.

## Directory Structure

```text
brand-kit/
├── guidelines/
│   └── glm.tokens.json          # Machine-readable color hex tokens and presets
├── logos/
│   ├── GLM-BIRD-Color.svg       # Two lime birds icon mark
│   └── GLM-black-Text-Color-Bird.svg # Full wordmark with birds
├── graphics/
│   ├── email.png                # Exact Globe+ email review UI screenshot
│   ├── menu.png                 # Exact Globe+ purchase menu screenshot
│   ├── sales.png                # Exact Globe+ sales order table screenshot
│   └── stock.png                # Exact Globe+ stock inquiry screenshot
├── persona/
│   └── glm-persona.md           # Tone of voice, Flippy agent narrative, dos and don'ts
├── audio/
│   ├── sfx/                     # Standard sound effect cues (.wav)
│   └── bgm/                     # Background music loops (.wav)
└── references/
    └── flippy-video-script.md   # Reference 64s video script for Flippy AI Agent
```
