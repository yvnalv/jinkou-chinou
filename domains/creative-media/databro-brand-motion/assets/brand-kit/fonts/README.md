# Databro Brand Fonts

Drop local font files (`.ttf`, `.otf`, `.woff2`) for Databro Studio in this folder (`assets/brand-kit/fonts/`):
- **Primary Display & Headings**: `PlusJakartaSans-ExtraBold.ttf`, `PlusJakartaSans-Bold.ttf`, `PlusJakartaSans-SemiBold.ttf`
- **Body & Subtitle (`Belajar Data Science`)**: `Inter-Regular.ttf`, `Inter-Medium.ttf`
- **Terminal & CLI Code**: `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Bold.ttf` (or Windows `Consolas`)
