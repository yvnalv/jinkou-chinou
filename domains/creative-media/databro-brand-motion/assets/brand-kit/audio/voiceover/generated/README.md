# Generated Voiceover & Word Timestamp Output Folder

Store synthesized per-video voiceover tracks and their aligned timestamp JSON files here:
- `voiceover.wav` / `voiceover.mp3` — Referenced via `voiceoverSrc="brand-kit/audio/voiceover/generated/voiceover.wav"` on `<DatabroBaseCanvas />`.
- `timestamps.json` — Word/phrase start and end timestamps converted into `CaptionPhraseCue[]` (`{ text, startFrame, endFrame }`) for the fixed `Y = 1480px` Closed Captions.
