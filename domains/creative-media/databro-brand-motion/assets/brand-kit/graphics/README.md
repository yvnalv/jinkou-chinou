# Databro Graphic Assets (Emblems, UI Frames & Overlays)

Store reusable graphic assets inside these subfolders:
- `emblems/` — `.svg` or `.png` line-art mascots and tool icons placed inside the `#F2EBE1` warm cream emblem circle (e.g., Ollama mascot, database cylinder, Python logo).
- `ui-frames/` — Reusable browser, installer, or Windows Terminal (`Command Prompt`) frame graphics.
- `overlays/` — 4-point sparkle vectors, cursors, and `#D92D20` red callout boxes.
