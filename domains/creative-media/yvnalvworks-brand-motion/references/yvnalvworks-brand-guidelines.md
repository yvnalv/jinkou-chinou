# yvnalvworks Brand Guidelines

## 1. Visual Identity Principles
`yvnalvworks` is the personal engineering studio brand of Yovan Alvianto.
The visual identity is modeled on high-performance developer tools, terminal elegance, and modern technical documentation (inspired by Lucide, Linear, and Vercel).

### Strictly Prohibited Visual Elements:
- **No generic AI aesthetics**: No purple/pink nebula gradients, glowing neon orbs, or floating magic sparkle emojis (`✨` is reserved only for Notion status).
- **No stock illustrations**: No cartoon robots, isometric floating islands, or generic 3D human figures.
- **No heavy shadows or skeumorphic bevels**: Everything is flat matte, razor-sharp, with 1px subtle borders.

## 2. Color Palette

| Token Name | Hex Code | Usage |
|---|---|---|
| **Canvas** | `#121212` | Main screen background (deep matte charcoal, non-pure black) |
| **Card Dark** | `#18181b` | Background of dark containers and code blocks |
| **Card Border** | `#27272a` | 1px subtle border for dark cards |
| **Electric Lime** | `#C1FF72` | Signature accent: punchline text highlights, solid framework cards |
| **Text Headline** | `#F0ECE2` / `#FFFFFF` | Primary headings, poster typography |
| **Text Secondary**| `#8E8E93` | Explanatory sentences and captions |
| **Text Muted**    | `#71717A` | Slide indicators (`01 / 05`), domain watermarks, tags |
| **Danger**        | `#EF4444` | Anti-pattern warnings and error states |

---

## 3. Typography Rules

1. **Primary Interface & Headlines**: `Inter`
   - Tracking: tight letter-spacing (`-0.035em`) for large headlines.
   - Weights: 800 (ExtraBold) for main punches, 600 (SemiBold) for sub-headings, 400 (Regular) for body.
2. **Code & Telemetry**: `JetBrains Mono` or `Geist Mono`
   - Weights: 500 (Medium).
   - Used for slide numbers, schema keys, terminal outputs, and system metrics.

---

## 4. Lucide Monoline SVG Standard
All visual icons, diagrams, and cards MUST follow Lucide design guidelines (`https://lucide.dev`):
- `viewBox="0 0 24 24"`
- `fill="none"`
- `stroke="currentColor"` or `stroke="#C1FF72"`
- `stroke-width="2"`
- `stroke-linecap="round"`
- `stroke-linejoin="round"`
- Minimal visual density, 24px grid base.
