# Lucide Icon Specification for yvnalvworks

All icons used across yvnalvworks graphics and slides MUST follow the official Lucide icon design system (lucide.dev).

## Technical SVG Rules
- **ViewBox**: `0 0 24 24`
- **Fill**: `none` (strictly no filled vector shapes)
- **Stroke**: `#C1FF72` (Electric Lime) or `#FFFFFF` (White) or `currentColor`
- **Stroke Width**: `2px`
- **Stroke Linecap**: `round`
- **Stroke Linejoin**: `round`

## Standard Icon Mappings for Engineering Concepts

| Concept | Recommended Lucide Icon | SVG Name |
|---|---|---|
| Evals / Test Suites | CheckCheck | `check-check` |
| JSON / Pydantic Schema | Braces | `braces` |
| Architecture / Layers | Layers | `layers` |
| Latency / Performance Budgets | Gauge | `gauge` |
| Telemetry / Observability | Activity | `activity` |
| Resilience / Fallback | ShieldCheck | `shield-check` |
| Camera / Optics | Camera | `camera` |
| Terminal / CLI | Terminal | `terminal` |
| Storage / Cache | Database | `database` |
| Network / API | Network | `network` |
