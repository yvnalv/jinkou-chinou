# ai-engineering

Building products on foundation models: prompting and context engineering, structured outputs, tool calling, retrieval-augmented generation, agents and agent protocols (MCP, A2A), evaluation of AI systems, guardrails and AI security, LLM observability and cost control, and fine-tuning, distillation, and serving of models when justified. Provider-neutral across hosted APIs and open-weights models. Classic predictive modeling and statistics belong in `data-science`; general software architecture in `software-engineering`; the interface of AI features in `ux-design`.

Core persona: `the-ai-engineer`. Specialized skills (for example a RAG pipeline builder, an MCP server builder, or an eval-suite builder) are named descriptively, without `the-`.
