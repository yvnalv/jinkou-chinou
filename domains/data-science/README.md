# data-science

Turning data into understanding and decisions: acquiring and mining data from the web, exploring and profiling datasets, data quality assessment, statistics and hypothesis testing, experimentation (A/B test design and analysis), causal inference, visualization, exploratory and explanatory modeling, and communicating findings. Building, deploying, and operating predictive models belongs in `ml-engineering`; applications on large language models in `ai-engineering`.

Core persona: `/the-miner` (web scraping, data collection, and extraction). Specialized skills are named descriptively, without `the-`.
