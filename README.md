# jinkou-chinou

人工知能 — a personal collection of AI skills for **Claude Code**, the **Claude Code VS Code extension**, and **claude.ai**, organized by domain of expertise.

Every skill has the same shape, defined in [SKILL_STANDARD.md](SKILL_STANDARD.md). Each domain can have one **core** persona skill (`the-architect`, `the-data-scientist`, …) and any number of **specialized** skills with descriptive names (`exploratory-data-analysis`, …).

## Quick start

```text
# install every domain skill into ~/.claude/skills (linked: repo edits apply immediately)
python tools/skills.py install --all

# or just one
python tools/skills.py install exploratory-data-analysis

# build a zip to upload on claude.ai (Settings → Capabilities → Skills)
python tools/skills.py package exploratory-data-analysis
```

Then type `/` in Claude Code or the VS Code extension and pick the skill, or just describe the task and let Claude choose it. New skills show up in new sessions.

## Creating a skill

Open this repository in Claude Code and run `/the-skillsmith` (or just ask for a new skill). It follows [SKILL_STANDARD.md](SKILL_STANDARD.md), scaffolds with `tools/skills.py new`, and finishes with `tools/skills.py validate`. Rules for AI agents working here are in [CLAUDE.md](CLAUDE.md).

## Layout

```text
jinkou-chinou/
├── SKILL_STANDARD.md          # the rules every skill follows
├── CLAUDE.md                  # instructions for AI agents in this repo
├── .claude/skills/            # repo-local meta skills (the-skillsmith)
├── tools/
│   ├── skills.py              # list | validate | new | catalog | install | uninstall | package
│   └── templates/             # skill skeleton
└── domains/
    └── <domain>/
        ├── README.md          # domain scope + skill list
        └── <skill>/           # SKILL.md, README.md, config/skill.yaml, [references/ scripts/ assets/ evals/]
```
